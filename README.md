## Tech Stack

### Core Framework
- **Next.js 16 (App Router)** — SSR, SSG, and Turbopack for ultra-fast local development
- **React 19 & TypeScript** — Strict type safety across 50+ custom UI components

### 3D & Physics
- **Three.js & React Three Fiber** — WebGL-powered 3D rendering
- **Rapier Physics** — Real-time physics simulation (interactive lanyard ID card)
- **Custom GLSL Shaders** — Warp / hyperspeed background effects

### Animation & UI
- **Framer Motion & GSAP** — Complex choreographies, micro-interactions, page transitions
- **Tailwind CSS & Shadcn UI** — Utility-first design with Radix UI accessibility primitives
- **Lenis** — Premium smooth scroll

### Integrations
- **Dual-LLM AI Chatbot** — Groq (LLaMA 3.1) + Google Gemini failover with portfolio RAG context
- **GitHub GraphQL** — Live repo stats, activity heatmaps, language breakdown
- **WakaTime API** — Real-time coding telemetry
- **Next-Intl** — EN/ID bilingual support

## Local Setup

### Prerequisites
- Node.js >= 18.0.0
- npm >= 9.0.0

### Steps

```bash
# Clone
git clone https://github.com/vishnuvardhanburri/vishnuvardhanburri.git
cd vishnuvardhanburri

# Install dependencies
npm install

# Configure environment — create .env.local
NEXT_PUBLIC_GITHUB_USERNAME=vishnuvardhanburri
GITHUB_TOKEN=your_github_pat
WAKATIME_API_KEY=your_wakatime_key
GROQ_API_KEY=your_groq_key
GEMINI_API_KEY=your_gemini_key

# Start dev server
npm run dev
# → http://localhost:3000

# Production build
npm run build && npm start
```
